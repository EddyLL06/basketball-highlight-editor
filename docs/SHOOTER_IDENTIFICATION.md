# 自动识别出手者（桌面测试版）

入口位于“审核 → 射手快标”的“自动识别出手者”。这是独立分析任务，
不会随原视频扫描自动运行。先正常分析视频、生成候选，再按需运行识别。

第一次运行会生成代理人物画面。在参考图区选定球员，开启“点图选参考”，
即可连续点击人物图加入图库；再次点击同一张图可以移除。框错人或要换帧时，
点图片上的调整按钮。每人至少两次不同出手，建议 3–5 张清楚、
角度不同的图片。参考图库属于当前项目，可供项目内多个视频复用。
再次点击识别按钮后会关联名字；有效画面和人物特征优先复用缓存。

有结果的卡片直接显示姓名建议。点姓名确认，点其他姓名纠正，也可一次
“采用本次建议”。更换画面人物后，旧人物的姓名建议不会继续套用。
图片详情内提供全景、人物切换、其他帧、看视频、不确定和清除操作。
添加球员沿用原有弹窗，每张卡片始终保留入口。

人工选择和自动建议分别保存。重跑不覆盖已保存的球员归属；批量采用会
跳过已有名字或明确标为不确定的候选，并保留 `accepted_suggestion` 来源。
仅明确确认的参考图进入图库，保存名字不会自动把图片加入图库。
Made/Missed 和片段取舍独立保存，未进球也可以标注射手。

识别只读取已有分析代理；篮球搜索限于候选附近的短时间窗，人物检测
限于估计出手位置的局部区域。失败时仅小幅扩大人物区域重试；球搜索的
扩大结果与首轮记录分开缓存。没有代理时保留人工快标并提示先完成分析。
任务可取消，模型在本地运行，安装后的 App 不下载模型。

本轮安装验证面向 macOS Apple Silicon。fork 的 `Shooter App preview`
工作流复用原有 macOS 打包脚本生成测试 DMG，不发布正式 Release、OSS
或更新通道。模型在 CI 中按固定来源及 SHA-256 准备，随完整测试包分发。
原正式发布工作流与 Windows 打包流程保持原样。

参考模型：OSNet x0.25 / MSMT17（MIT；许可证随包保存），
人物检测使用固定版本 YOLO11n（Ultralytics AGPL-3.0）。来源和校验值见
`scripts/prepare_shooter_models.py`。外观相似度是匹配证据，不是正确率概率。
